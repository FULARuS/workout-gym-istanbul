# Workout Gym

[Открыть клиентский предпросмотр](https://fularus.github.io/workout-gym-istanbul/). В этой версии форма проверяет поля и готовит заявку для отправки через WhatsApp.

Для локального запуска откройте папку проекта и выполните команду.

```powershell
python server.py
```

[Главная](http://127.0.0.1:8849/) · [Абонементы и запись](http://127.0.0.1:8849/uyelik) · [Видеотур и филиалы](http://127.0.0.1:8849/salon)

Сервер сохраняет заявки в `data/leads.sqlite3`, в таблице `leads`. К файлу можно обратиться из папки проекта. Форма показывает код заявки после сохранения. Телефон и ссылка WhatsApp взяты из объявления Workout Gym.

Для проверки с отдельной базой укажите путь через `--database` и другой порт через `--port`.

Команда `python build_pages.py` собирает клиентский предпросмотр в папку `dist`. GitHub Actions публикует эту сборку при обновлении ветки `main`.
